# CanvasNet Tool Test Fixtures

These files are test inputs for the `canvasnet` tool. Every one is an original work of this project (or was
generated by this project), so there are no third-party licensing constraints beyond the repository's own license.
Most test images are not stored here at all: the tests generate rasters (PNG, BMP, TIFF, JPEG, GIF) in memory
with the CanvasNet codecs and write them to a temporary directory, so that no binary file has to be reviewed.

## Files

<!-- markdownlint-disable MD013 -->
| File | Description |
| ---- | ----------- |
| `shapes.svg` | A 100x80 SVG drawing made for these tests: a red, a blue, and a half-transparent green rectangle on a transparent background, with a viewBox equal to its size so that every shape edge falls on a whole pixel. Written by hand; no font or external reference. |
| `gradient-100x70.jp2` | A 100x70 JPEG 2000 (JP2) image of gradients, a white disc, and seeded noise. There is no JPEG 2000 encoder in the CanvasNet libraries, so this file is a copy of `lossy_q30.jp2` from the `Jpeg2000Fixtures` folder of the `DemaConsulting.CanvasNet.Tests` project; see the `README.md` there for how it was generated (ImageMagick, from a synthetic image created by this project). |
| `cube.scad` | A 20x10x10 block with a round hole through its top, as an OpenSCAD model with one module, one function, and a variable (`width`) that `-D width=...` overrides. Written by hand for these tests; it has no `include`, no `use`, no text, and no font. |
| `baskets.vl.json` | A Vega-Lite bar chart of three inline values (a 120x80 data rectangle, a title, a nominal x axis, and a quantitative y axis). Written by hand for these tests; no data file, no URL, and no custom font. |

## SCAD models generated by the tests

Every other OpenSCAD model the tests need (a model that looks different from every side, models that `include` and
`use` other files, models with a syntax error, an unsupported construct, a failed `assert`, or a runaway recursion,
and the stress models that probe for unexpected exceptions) is a few lines of text that the test writes into a temporary
directory (`FixtureFactory.Scad.cs` and the tests themselves). They are original works of this project - written by
hand for these tests, with no content taken from another model, library, or sample - so there are no licensing
constraints beyond the repository's own license.

## Documents generated by the tests

The PDF, PPTX, and VSDX documents are not stored here either: the test project writes them into a temporary
directory (`FixtureFactory.Pdf.cs`, `FixtureFactory.Pptx.cs`, and `FixtureFactory.Vsdx.cs`). They are original works
of this project - written by hand for these tests, with no content copied from another document, a library fixture,
or a third-party sample - so there are no licensing constraints beyond the repository's own license. None has text
or a font, so that the pixels do not depend on the fonts of the machine.

<!-- markdownlint-disable MD013 -->
| Document | Description |
| -------- | ----------- |
| PDF | Two pages of 144x96 points, as hand-written objects with a cross-reference table: page 1 has a red rectangle over its top-left quarter and a blue one over its bottom-right quarter; page 2 is rotated by 90 degrees and is green with a yellow square. Variants with malformed page content and with an unsupported encryption handler test the error mapping. |
| PPTX | Two slides of 5 by 3.75 inches, as an Office Open XML package (a presentation, its slides, one layout, one master, and one theme) assembled with `System.IO.Compression`: slide 1 has a red rectangle over its left half, slide 2 a blue one over its top half. Variants add a picture whose media is an EMF file (a few arbitrary bytes, which the renderer skips by its extension) or a shape with a preset geometry name that does not exist. |
| VSDX | Two pages as an Open Packaging Convention package assembled with `System.IO.Compression`: `First` is 4 by 3 inches with a red rectangle over its top-left quarter, `Second` is 3 by 4 inches with a blue one over its bottom half. A variant adds a shape with a geometry row of a kind that does not exist. |
<!-- markdownlint-enable MD013 -->

The package layouts follow the technique the test projects of the PPTX and VSDX systems use for their own
synthetic packages; no fixture file of those projects is used.

## Notes

The tests compare what the tool writes with what the codecs decode from the same file, so the JPEG 2000 file needs
no reference pixels of its own.
