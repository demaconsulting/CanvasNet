# JPEG 2000 Test Fixtures

These fixtures give `Jpeg2000Codec` independent evidence from a real-world encoder. They were
generated by this project with [ImageMagick](https://imagemagick.org/) 7.1.2 (Q16), whose
JPEG 2000 delegate is the OpenJPEG library, from synthetic images that this
project created. No third-party image content is used or included, so there are no external
licensing constraints beyond the repository's own license.

## Sources

| File | Description |
| ------ | ------------- |
| `source_rgb.png` | 100x70, 8-bit RGB: gradients, a white disc and seeded Gaussian noise |
| `source_gray.png` | 100x70, 8-bit gray: `source_rgb.png` converted to gray |
| `source_rgba.png` | 100x70, 8-bit RGBA: `source_rgb.png` with a horizontal opacity gradient |

Generated with (the noise is deterministic through the fixed `-seed`):

```pwsh
magick -size 100x70 -depth 8 gradient:red-blue `
  "(" -size 100x70 gradient:black-white -rotate 90 ")" -compose Screen -composite `
  -fill white -draw "circle 50,35 50,15" -seed 12345 -attenuate 0.08 +noise Gaussian `
  -alpha off -depth 8 -strip -define png:exclude-chunks=all PNG24:source_rgb.png
magick source_rgb.png -colorspace Gray -strip -define png:exclude-chunks=all PNG8:source_gray.png
magick source_rgb.png "(" -size 100x70 gradient:white-black -rotate 90 -alpha off ")" `
  -alpha off -compose CopyOpacity -composite -define png:exclude-chunks=all PNG32:source_rgba.png
```

## JPEG 2000 Fixtures

All fixtures are single-tile, 5/3 reversible wavelet streams (the only wavelet ImageMagick 7.1.2
selects). Each was checked directly against its marker bytes (COD progression order, layer count,
decomposition levels, MCT flag, SIZ component count and bit depth) and decoded back by ImageMagick
(`magick fixture -depth 8 out.png`, `magick compare -metric AE`) before committing.

| File | Source | Options | Verified by OpenJPEG |
| ------ | -------- | --------- | ---------------------- |
| `lossless_rct.jp2` | RGB | `jp2:rate=1`; LRCP, 5 levels, RCT | AE 0 |
| `progression_rlcp.jp2` | RGB | `jp2:rate=1`, `jp2:progression-order=RLCP` | AE 0 |
| `progression_rpcl.jp2` | RGB | `jp2:rate=1`, `jp2:progression-order=RPCL` | AE 0 |
| `progression_pcrl.jp2` | RGB | `jp2:rate=1`, `jp2:progression-order=PCRL` | AE 0 |
| `progression_cprl.jp2` | RGB | `jp2:rate=1`, `jp2:progression-order=CPRL` | AE 0 |
| `resolutions3.jp2` | RGB | `jp2:rate=1`, `jp2:number-resolutions=3` (2 levels) | AE 0 |
| `layers3.jp2` | RGB | `jp2:rate=8,4,1` (3 quality layers, last lossless) | AE 0 |
| `gray.jp2` | gray | `jp2:rate=1` (1 component) | AE 0 |
| `alpha.jp2` | RGBA | `jp2:rate=1` (4 components, opacity channel) | AE 0 |
| `depth16.jp2` | RGB | `-depth 16 -define jp2:rate=1` (16-bit samples) | AE 0 after `-depth 8` |
| `lossless_raw.j2k` | RGB | `jp2:rate=1`, raw codestream without JP2 boxes | AE 0 |
| `lossy_q30.jp2` | RGB | `jp2:quality=30` (truncated, lossy) | PSNR 31.7 dB |

Generated with, for example:

```pwsh
magick source_rgb.png -define jp2:rate=1 -define jp2:progression-order=RPCL progression_rpcl.jp2
magick source_rgb.png -define jp2:rate=8,4,1 layers3.jp2
magick source_rgb.png -depth 16 -define jp2:rate=1 depth16.jp2
magick source_rgb.png -define jp2:quality=30 lossy_q30.jp2
```

## Variants Dropped

ImageMagick 7.1.2 exposes no tile, precinct or 9/7 irreversible options (only
`jp2:number-resolutions`, `jp2:progression-order`, `jp2:quality`, `jp2:quality-layers`,
`jp2:rate` and `jp2:reduce-factor`), and a probe confirmed the markers of such attempts were
unchanged. Tiles, precincts and the 9/7 wavelet are therefore covered only by the test-only
encoder in `Jpeg2000CodecTests`.

The lossless fixtures are compared against the source PNG (decoded with `PngCodec`) for exact
equality; `lossy_q30.jp2` is compared with a PSNR threshold.
