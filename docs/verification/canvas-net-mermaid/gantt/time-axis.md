### TimeAxis Unit Verification Design

This document describes the unit-level verification strategy for the `TimeAxis` unit in the
`DemaConsulting.CanvasNet.Mermaid.Gantt` namespace: the internal static `TimeAxis` (the d3 intervals, tick generator,
tick step, and time format, in three partial files), the date `JsDate`, the interval `TimeInterval`, and the time scale
`TimeScale`.

#### Verification Approach

The unit is verified in two ways. Its functions are called directly with chosen dates and compared with the values that
JavaScript and d3 give for the same input, stated in the tests as literals: the getters and setters of dates, the
floors, ceilings, offsets, ranges, and counts of the intervals, the special `every` intervals, the ticks and tick steps,
the rounded map of the time scale, and the formatted texts. And every case of the upstream vector file
`Fixtures/upstream-vectors/time-axis.json` is computed and compared with the result that d3 recorded for it: 1,166
cases of nine kinds (date getters, dates from components, setters, interval floors, ceilings, offsets, and counts,
ranges, ticks, tick steps, scale maps, and formats). The vector file is generated by
`tools/visual-diff/mermaid/gen-time-vectors.mjs`, which runs the d3 modules that Mermaid bundles directly in Node with
the time zone set to UTC, refuses to run in another time zone or with a d3 module that is not the one Mermaid's bundle
contains, and writes invalid dates, NaN, and the infinities as null; the dates, domains, and specifiers are original,
the expected values d3's. The gantt charts that use the unit are verified against the goldens drawn by Mermaid at the
system level by the reference layout tests.

No mocking or stubbing is used; the functions are pure. The internal types are reached through the test assembly's
`InternalsVisibleTo` access, and the vector file is read by the shared helper `UpstreamVectors`.

Unit tests reside in `TimeAxisTests.cs` within the `DemaConsulting.CanvasNet.Mermaid.Tests` project, in the `Gantt`
folder.

#### Test Environment

- **Framework**: xUnit v3 running under the .NET SDK
- **Execution**: `dotnet test` invoked by `build.ps1` and the CI pipeline
- **Mocking**: None required
- **Test data**: The vector file `Fixtures/upstream-vectors/time-axis.json`, copied to the test output
- **Isolation**: The functions are pure; the vector file is only read

#### Acceptance Criteria

A unit-level test run passes when every scenario below passes without error or exception beyond those explicitly
asserted. Any time value, date component, tick, step, mapped value, or text that differs from the asserted JavaScript or
d3 value, or from the value d3 recorded in a vector case, constitutes a failure.

#### Unit-Level Test Scenarios

##### CanvasNetMermaid-Gantt-TimeAxis-Dates: JavaScript Dates In UTC

**Tests**: `TimeAxisTests.TimeAxis_JsDate_EcmaScriptArithmetic_MatchesJavaScript`,
`TimeAxisTests.TimeAxis_JsDate_SettersOfInvalidDate_FollowJavaScript`,
`TimeAxisTests.TimeAxis_UpstreamVector_MatchesD3`,
`TimeAxisTests.TimeAxis_Vectors_FileHasEveryKind_EnoughCases`

Asserts that the time value -1 is the year 1969, the month 11, the day 31, the weekday 3, and 23:59:59.999; that
2024-02-29 with the month set to 12 is `2025-01-29T00:00:00.000Z`, the month carried into the year; that the year 99 of
the constructor is `1999-01-01T00:00:00.000Z`; and that 275760-09-14, beyond 8.64e15 milliseconds, is invalid, written
`Invalid Date`, with a year of NaN. Asserts that the year setter of an invalid date gives `2024-01-01T00:00:00.000Z`,
starting from time zero, while the month and hours setters keep it invalid. Asserts that every `date`, `components`,
and `set` case of the vector file matches the getters, the time value, or the set date that JavaScript recorded, and
that the file holds at least 1,000 cases and at least 6 of each of its nine kinds.

##### CanvasNetMermaid-Gantt-TimeAxis-Intervals: The d3-time Intervals

**Tests**: `TimeAxisTests.TimeAxis_Intervals_FloorCeilOffsetRangeCount_FollowD3`,
`TimeAxisTests.TimeAxis_Every_SpecialCases_FollowD3`,
`TimeAxisTests.TimeAxis_UpstreamVector_MatchesD3`,
`TimeAxisTests.TimeAxis_Vectors_FileHasEveryKind_EnoughCases`

Asserts that for 2024-06-12T10:30Z the day floor is `2024-06-12T00:00:00.000Z` and the day ceiling
`2024-06-13T00:00:00.000Z`, the Monday floor `2024-06-10T00:00:00.000Z`, the month offset by 2.7 (floored to 2)
`2024-08-12T10:30:00.000Z`, the range of every second day over the next six days `2024-06-13`, `2024-06-15`, and
`2024-06-17` at midnight, and the count of Sunday weeks since 2024-01-01 23. Asserts that every 50 milliseconds floors
123 milliseconds to 100; that every 10 years floors the date to `2020-01-01T00:00:00.000Z` and has no count; that every
0 days is no interval and every 1.5 days is the day interval itself; and that `every` of a filtered interval and `count`
of the decade interval throw `InvalidOperationException`. Asserts that every `interval` and `range` case of the vector
file matches the floor, the ceiling, the offsets, the counts, and the range that d3 recorded.

##### CanvasNetMermaid-Gantt-TimeAxis-Ticks: The Ticks And The Tick Step

**Tests**: `TimeAxisTests.TimeAxis_Ticks_MonthDomain_GivesTwoDayTicksAndEmptyForInvalid`,
`TimeAxisTests.TimeAxis_UpstreamVector_MatchesD3`,
`TimeAxisTests.TimeAxis_Vectors_FileHasEveryKind_EnoughCases`

Asserts that the default ticks of the domain from 2024-01-01 to 2024-02-01 are 17 ticks two days apart, the second one
`2024-01-03T00:00:00.000Z` (31 days ask for steps of about 3 days, and two days is the nearer row of the table); that a
domain of invalid dates gives no ticks; and that the tick step from 0 to 1 for 10 ticks is 0.1 and from 50 to 0 for 10
ticks is -5. Asserts that every `ticks` and `tickStep` case of the vector file matches the ticks and the step that d3
recorded.

##### CanvasNetMermaid-Gantt-TimeAxis-Scale: The Rounded Time Scale

**Tests**: `TimeAxisTests.TimeAxis_TimeScale_RangeRound_FollowsJavaScriptRounding`,
`TimeAxisTests.TimeAxis_UpstreamVector_MatchesD3`,
`TimeAxisTests.TimeAxis_Vectors_FileHasEveryKind_EnoughCases`

Asserts that the scale from the domain 0 to 4 onto the range 0 to 10 maps 1 to 3 (2.5 rounded up), 2 to 5, and 3 to 8
(7.5 rounded up); that -2.5 rounds to -2, as `Math.round` rounds; that the descending domain 4 to 0 maps 0 to 10; that
the domain of zero length at 7 maps 123 to 5, the middle of the range; and that NaN maps to NaN. Asserts that every
`scale` case of the vector file matches the values that d3 recorded.

##### CanvasNetMermaid-Gantt-TimeAxis-Format: The Time Format

**Tests**: `TimeAxisTests.TimeAxis_Format_Directives_FollowD3TimeFormat`,
`TimeAxisTests.TimeAxis_UpstreamVector_MatchesD3`,
`TimeAxisTests.TimeAxis_Vectors_FileHasEveryKind_EnoughCases`

Asserts that 2024-06-02T09:05:07.012Z formats with `%Y-%m-%d` as `2024-06-02`, with `%c` as `6/2/2024, 9:05:07 AM`,
with `%a %b %e|%-d|%0d|_%-e` as `Sun Jun  2|2|02|_2` (the space pad of `%e` and the pad modifiers), and with
`%V %u %Z %% %k` as `22 7 +0000 % k` (the ISO week, the ISO weekday, the zone, a percent sign, and an unknown directive
as its character); and that the invalid date formats with `%Y-%b / %I%p` as `0NaN- / 12AM`. Asserts that every
`format` case of the vector file matches the texts that d3 recorded.
